# Permissions

What each role can do. The matrix applies inside every [workspace](/docs/workspaces/personal-vs-org) — personal workspaces always have you as Admin; org workspaces invite people in at the role you pick.

## Permission Matrix

| Action | Viewer | Member | Admin |
|--------|--------|--------|-------|
| View apps & logs | Yes | Yes | Yes |
| View metrics | Yes | Yes | Yes |
| View config vars | Yes | Yes | Yes |
| Deploy apps | — | Yes | Yes |
| Manage config vars | — | Yes | Yes |
| Manage domains | — | Yes | Yes |
| Manage databases | — | Yes | Yes |
| Restart / stop / start | — | Yes | Yes |
| Scale processes | — | Yes | Yes |
| Create apps | — | Yes | Yes |
| Delete apps | — | — | Yes |
| Manage servers | — | — | Yes |
| Manage team members | — | — | Yes |
| Manage billing | — | — | Yes |
| Delete databases | — | — | Yes |
