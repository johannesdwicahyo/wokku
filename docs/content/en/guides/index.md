Pick a recipe and follow it top to bottom. New to Wokku? Start with the [Quickstart](/docs/getting-started/first-deploy) or a [framework guide](/docs/frameworks/index).

## Recipes

- **[Run background workers](/docs/guides/background-workers)**: queues, consumers, any non-web process
- **[Schedule tasks (cron)](/docs/guides/scheduled-tasks)**: run a command on a schedule
- **[Add a database](/docs/databases/create-link)**: Postgres, MySQL, MariaDB, MongoDB or Redis for your app
- **[Deploy with a Dockerfile](/docs/guides/dockerfile)**: full control over the build
- **[Deploy from a monorepo](/docs/guides/monorepo)**: ship one app out of a subdirectory
- **[Roll back a bad deploy](/docs/guides/rollback)**: go back to a previous release
- **[Preview deploys for pull requests](/docs/guides/preview-deploys)**: a live URL per PR
- **[Deploy with Claude (MCP)](/docs/guides/deploy-with-claude)**: create and deploy apps from your editor
