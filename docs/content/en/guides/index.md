# How-To Guides

Task-focused recipes for common deployment jobs. Each one is end-to-end —
follow it top to bottom and the task is done.

New to Wokku? Start with [Your First Deploy](/docs/getting-started/first-deploy)
or a [framework guide](/docs/frameworks/index) first.

## Recipes

- **[Run background workers](/docs/guides/background-workers)** — queues, consumers, any non-web process
- **[Schedule tasks (cron)](/docs/guides/scheduled-tasks)** — run a command on a schedule
- **[Add Postgres + Redis](/docs/guides/postgres-redis)** — wire a database and cache to one app
- **[Deploy with a Dockerfile](/docs/guides/dockerfile)** — full control over the build
- **[Deploy from a monorepo](/docs/guides/monorepo)** — ship one app out of a subdirectory
- **[Roll back a bad deploy](/docs/guides/rollback)** — instant revert to a previous release
- **[Preview deploys for pull requests](/docs/guides/preview-deploys)** — a live URL per PR
- **[Deploy with Claude (MCP)](/docs/guides/deploy-with-claude)** — provision + deploy from your editor
